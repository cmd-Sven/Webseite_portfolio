# Lebenslauf

Der Landingpage-Button „Lebenslauf“ lädt das **öffentliche** Storage-Objekt:

`portfolio-public/lebenslauf.pdf`

Beim Admin-Upload des Master-Lebenslaufs wird dorthin automatisch gespiegelt.
